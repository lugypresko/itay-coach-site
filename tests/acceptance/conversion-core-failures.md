# Conversion Core failure acceptance scenarios

- A database failure never exposes a stack trace or personal data and shows a recovery path.
- An email provider failure does not erase a successfully created report; the report remains viewable and the delivery state is honest.
- A missing pattern uses the insufficient-evidence route rather than a default diagnosis.
- A declined contact request still returns the micro-insight and diagnosis allowed by the flow.
- Analytics failure does not block report creation or routing.
