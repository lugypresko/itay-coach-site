# Legacy diagnostic API inventory

Reviewed 2026-09-16 for the `site-next` migration. The new conversational state
machine is `/api/player-trap/conversation`; legacy routes must not provide a
second writable path into that state.

| Endpoint | Current callers | Decision | Reason |
|---|---|---|---|
| `GET /api/player-trap/session` | No source caller found; historical clients may still initialize the old flow | Retain temporarily | Returns a compatibility snapshot and can initialize the old session cookie. It does not write conversational state supplied by a client. |
| `POST /api/player-trap/session` | No source caller found | Retire (410) | Previously accepted forged `currentState`, `answers`, `signals`, and `completedTurns`, creating a state-write bypass. |
| `GET /api/player-trap/diagnostic` | No source caller found | Retain temporarily | Existing old diagnostic clients may restore a session while migration is staged. |
| `POST /api/player-trap/diagnostic` | No source caller found | Retire after migration | Legacy state transition endpoint; it must not become another writer for the new conversation contract. |
| `POST /api/player-trap/lead` | Legacy Player Trap page and older clients | Retain | Historical lead/report creation remains supported. It is separate from the new anonymous conversation store. |
| `GET /api/player-trap/diagnosis-call` | Historical report CTA generated by `player-trap.ts` | Retain | Preserves historical report follow-up links; validates opaque token and 30-day TTL. |
| `POST /api/player-trap/diagnosis-call` | No source caller found | Retain temporarily | Historical integrations may post the token; validation and TTL must match GET before production use. |
| `GET /player-trap/report/[token]` | Historical email/report links | Retain | Read-only historical report surface, with opaque token and 30-day expiry. |

The inventory was based on the route tree and repository-wide source search. A
zero-caller result does not prove that a URL is unused: the endpoint may be in
old emails, bookmarks, or external integrations. The report surface and its
diagnosis-call endpoint therefore remain available while the writable legacy
paths are closed.
