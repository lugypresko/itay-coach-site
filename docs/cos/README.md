# Chief of Staff

The Chief of Staff operating model is the canonical reference for how the Authority Engine turns signals into recommendations.

Use this directory for:

- the executive operating model
- worker operating models
- recommendation boundaries
- escalation rules

Canonical documents:

- [Chief of Staff Operating Model](./CHIEF_OF_STAFF_OPERATING_MODEL.md)
- [Chief of Staff Delegation Matrix](./CHIEF_OF_STAFF_DELEGATION_MATRIX.md)
- [Chief of Staff Decision Loop](./CHIEF_OF_STAFF_DECISION_LOOP.md)
- Worker operating models live in [`/workers`](../../workers)

Operating rules:

- Workers are deterministic.
- Workers do not publish autonomously.
- Workers do not modify governance.
- Workers do not override human approval.
- Workers return recommendations or analysis only.
