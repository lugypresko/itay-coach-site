# Entity Authority Baseline Snapshot

Status: evidence collection template
Owner: human reviewer
Scope: baseline state of the entity graph before release verification and ongoing monitoring

## Purpose

Capture the starting authority state of the core entities so future changes can be measured against a fixed baseline.

This snapshot is a measurement artifact, not a publishing artifact.

- Itay Foyerstein

## Required fields per entity

- Name
- Canonical role
- Entity type
- Status
- Authority score
- Authority tier
- SameAs URLs
- Evidence URLs
- Target recommendation queries
- Relationship count
- Last reviewed at
- Notes

## Required relationship fields

- Source entity
- Target entity
- Relationship type
- Weight
- Rationale
- Evidence URLs
- Status
- Last reviewed at

## Evidence rules

- Use only approved, reviewable, or otherwise verifiable records.
- Do not fabricate sameAs URLs, evidence, or relationships.
- Distinguish between draft, review, approved, and active states.

## Output

The output of this snapshot is a baseline entity report that can be compared against later runs.
