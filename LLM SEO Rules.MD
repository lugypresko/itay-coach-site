# LLM SEO Rules

Every published page must include:

- Clear H1
- H2/H3 hierarchy
- Key Takeaways section
- Definition box
- Tables
- FAQ
- Schema markup
- Author credibility
- Last updated date
- Internal links
- Citation-worthy snippets
- Short answer section near the top
- Non-branded educational opening
- Clear CTA near the end

Each article must answer 5–10 specific questions users may ask AI tools.

Each article must include:
- aiSummary
- citationSnippet
- targetQuestions
- entityTags
- relatedPages
- schemaType
- lastReviewedAt
