# Acceptance Criteria

System is complete only when:

1. Payload CMS runs locally.
2. PostgreSQL is connected.
3. Admin can create Pillar, Cluster, FAQ, Framework and Case Study pages.
4. Next.js renders all content pages.
5. Each page has metadata and schema.
6. Internal links render correctly.
7. LangGraph workflow can generate a draft article.
8. Quality Gate can approve/reject content.
9. Approved content is saved to Payload.
10. Lead form sends email through Resend.
11. Sitemap and robots.txt exist.
12. Lighthouse scores are 90+ for SEO, performance, accessibility and best practices.
13. GitHub Actions run lint, typecheck and tests.
